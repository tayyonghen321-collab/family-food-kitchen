家庭美食厨房 PWA 安装说明（Redmi Pad Pro）

项目文件：
- index.html：主网页
- manifest.json：应用名称与安装设置
- service-worker.js：离线缓存
- icon.svg：应用图标

重要说明：
PWA 离线缓存需要 HTTPS 网站或 localhost 才能正常工作。不能仅把这些文件通过 USB 复制到平板后，就期待完整的 PWA 离线安装。

如果使用 GitHub Pages：
1. 在电脑打开 https://github.com/ 并登录/注册。
2. 新建 repository，例如 family-food-kitchen。
3. 上传本文件夹内的四个文件。
4. Settings -> Pages -> Build and deployment 选 Deploy from a branch；branch 选 main，folder 选 /(root)，保存。
5. 等待 GitHub Pages 给出 HTTPS 地址。
6. Redmi Pad Pro 用 Chrome 打开该地址，保持联网并等待网页加载完成。
7. Chrome 菜单 ⋮ -> Install app / Add to Home screen（安装应用/添加到主屏幕）。
8. 打开安装的应用一次，确认加载完成，再开飞行模式测试离线使用。
9. 用网页里的“备份数据”定期导出记录。

隐私提醒：
GitHub Pages 网址可被别人访问，因此它不是私密网站。不要上传私人信息。如果你要求网站完全不公开，请先不要使用 GitHub Pages；我们改走家庭自有设备的方案，设置会复杂一些。

功能：
- 离线食谱与材料份量计算
- 修改并保存每次实际用料
- 历史记录、口味与备注
- 自定义食谱
- 导出/导入备份
- 真正 AI 食谱功能尚未接入，需之后另行连接安全的 AI 后端
